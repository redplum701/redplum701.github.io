# Koubai SNS Rules

**Purpose:** This document defines how Koubai communicates in English across Discord, Bluesky, X, and Reddit. Each platform has a distinct role. The same copy must not be posted unchanged across all four platforms.

## 1. Core principle

Koubai has one consistent identity, but speaks differently in different communities.

- Keep Koubai's voice, values, and visual identity consistent.
- Adapt the subject, framing, length, tone, and call to action to each platform.
- A shared event or milestone may inspire several posts, but each post must be written specifically for its destination.
- Do not force every topic onto every platform. Publish only where it naturally belongs.
- Prefer useful, thoughtful contributions over posting frequency or promotional reach.

Koubai's public identity: **“Koubai is a creative identity exploring the worlds of code and poetry.”**

Core line: **“I can't sing or dance, so I write code.”**

Code and poetry are both forms of expression. Koubai's public-facing content is in English; planning and internal notes may be in Japanese.

## 2. Platform roles

### Discord — Koubai Atelier
**Role: Community, participation, and learning together.**

Discord is the closest, most interactive space: a workshop where people can learn, ask questions, follow progress, and exchange ideas.

Main content:
- Weekly progress and project updates
- JavaScript lesson questions and discussion
- Behind-the-scenes notes about reusable modules
- Development decisions and works in progress
- Community ideas and conversations

Use a welcoming, conversational tone. Invite genuine discussion rather than broadcasting announcements only. Keep the existing channel structure; do not create more channels unless there is a clear need.

### Bluesky — Koubai's Voice
**Role: Everyday thoughts, personality, creativity, and conversation.**

Bluesky is where people get to know Koubai beyond technical output. It should feel personal, warm, curious, and occasionally poetic.

Main content:
- A Thought for Today — a small reflection
- Little Discoveries — observations from coding or everyday life
- A Line of Poetry — a short original line or poem
- Behind the Screen — a small insight from the creative process
- Koubai's Moments — a visual paired with a thoughtful caption
- Questions to the World — open-ended questions that invite conversation

Keep promotional posts occasional. Let Koubai's character emerge through original words, images, and replies.

### X — Koubai Updates
**Role: Activities, technical updates, milestones, and discovery.**

X is the concise public update channel. Make the point quickly and clearly, and link to the relevant project when useful.

Main content:
- Development updates
- Short JavaScript tips
- Module Spotlights
- GitHub repository updates
- Official website updates
- Milestone announcements

Use clear, focused writing. Explain what changed, what was built, or why it matters. Participate in relevant conversations; avoid turning the account into a stream of links.

### Reddit — Koubai's Workshop
**Role: Technical knowledge, detailed explanations, and discussion.**

Reddit is for contributions that stand on their own and are useful to a relevant community. The substance of a post must matter more than promotion.

Main content:
- How I Built It — implementation explanations
- What I Learned — lessons from development
- Design Decisions — reasoning behind an approach
- Problem and Solution — a real technical challenge and its resolution
- Code Review Discussion — asking for constructive feedback
- Open Source Journey — reflections on building and maintaining modules

Always read and follow each subreddit’s rules before posting. Respect community norms. Do not use Reddit primarily to advertise Koubai, the website, or GitHub. Share links only when relevant and permitted.

## 3. Four content pillars

Use these pillars to maintain a coherent identity across platforms. The mix should vary by platform.

1. **CODE** — JavaScript, learning, reusable modules, technical experiments, and open-source development.
2. **CREATION** — making things, experiments, ideas, process, and the relationship between code and creativity.
3. **WORDS** — poetry, short reflections, language, and thoughtful observations.
4. **MOMENTS** — everyday details, atmosphere, visual work, and glimpses of the atelier.

Suggested emphasis:
- Discord: CODE and CREATION, with community interaction.
- Bluesky: WORDS and MOMENTS, alongside personal discoveries.
- X: CODE and project-related CREATION.
- Reddit: CODE and substantive technical CREATION.

Poetry and everyday-life posts should generally be centered on Bluesky rather than forced into Reddit.

## 4. Topic-to-platform guide

| Topic | Discord | Bluesky | X | Reddit |
|---|---|---|---|---|
| JavaScript learning | Questions and discussion | Learning discoveries | Short technical tips | Detailed explanations |
| 100 JavaScript Modules | Progress and discussion | Reflections on making them | Milestones and module highlights | Design and implementation details |
| Code and creativity | Idea exchange | Creative fragments | Project highlights | Technical analysis |
| Poetry | Occasional process notes | Poems and short lines | Occasional work announcements | Only when relevant to a genuine discussion |
| Koubai's everyday moments | Community conversation | Main home for this theme | Rare updates | Generally not a fit |
| Visual work | Feedback and process | Image with a thoughtful caption | Visual with a clear project update | Explain the technical process when relevant |

This guide is a default, not a requirement to post every topic everywhere.

## 5. Initial posting cadence

Start sustainably. Suggested starting rhythm:

| Platform | Initial cadence | Main purpose |
|---|---:|---|
| Discord | About once a week | Progress and community |
| Bluesky | About twice a week | Voice and connection |
| X | About twice a week | Activity and technical visibility |
| Reddit | About once a week | Knowledge and discussion |

Example weekly rhythm:
- Monday — Bluesky: A Thought for Today
- Tuesday — X: JavaScript Tip
- Wednesday — Discord: Weekly Progress
- Thursday — Bluesky: A Line of Poetry
- Friday — X: Module Spotlight
- Saturday — Reddit: How I Built It
- Sunday — Rest and review; no post required

This is a flexible starting point, not a quota. Skip a post rather than publish something thin or forced. Adjust frequency based on quality, community response, and available time.

## 6. Reworking one topic for multiple platforms

When an event or milestone is worth sharing in more than one place:

1. Identify the single underlying fact, achievement, question, or idea.
2. Decide which audiences would genuinely benefit from it.
3. Choose a different editorial angle for each relevant platform.
4. Write each post from scratch for that platform.
5. Use platform-appropriate detail, tone, and links.
6. Do not publish the same wording unchanged across platforms.

Example: when the 100 JavaScript modules are complete:
- Discord: share the journey, invite people to explore the work, and open a discussion.
- Bluesky: reflect on what the process taught Koubai or share a personal creative thought.
- X: announce the verified milestone concisely and link to the repository.
- Reddit: explain an interesting design decision or technical lesson, if it fits the subreddit.

Do not announce completion until all 100 modules have actually been verified as complete.

## 7. Writing and publishing standards

- Write public posts in natural English.
- Be clear, warm, thoughtful, and genuine.
- Avoid invented biography, credentials, education, work history, or personal experiences.
- Do not imply a long publishing history where none exists.
- Do not claim a project or milestone is complete before verification.
- Do not make every post promotional. Give readers something worthwhile even when no link is included.
- Use visuals when they add meaning; image credit may say: “Visual created with AI.”
- Keep calls to action relevant and low-pressure.
- Respect platform rules, community expectations, and the context of each conversation.
- Review each post before publishing for factual accuracy, tone, and destination.

## 9. Review

After the first month, review:
- Which topics created meaningful conversations?
- Which posts attracted readers who were genuinely interested?
- Was each platform's role clear?
- Was the cadence sustainable?
- Did any content feel duplicated or forced?

Improve the approach based on quality of engagement and usefulness, not follower counts alone.
