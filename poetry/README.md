# Poetry Atelier — Publishing Guide

Poetry Atelier is the home for Koubai's poems. The public pages are written in English.

## Add a poem

1. Copy `poem-template.html`.
2. Create a new file in this folder named `YYYY-MM-DD-short-title.html`.
3. Replace every bracketed placeholder: page title, description, date, and poem text.
4. Keep the poem's intentional line breaks inside the `.poem` element.
5. Add the new poem to the collection list in `index.html), newest first.
6. Preview the page on mobile and desktop before considering it ready.

## Editorial notes

- Publish only poems intentionally approved for public release.
- Do not invent a publication date or claim an older public release.
- Keep the poem itself faithful to the approved original.
- Keep each poem on its own page; the collection page should link to it.

The template is `poem-template.html`. It is a starting point, not a published poem.
