# Diary Atelier — Publishing Guide

Diary Atelier collects Koubai's dated notes. The public pages are written in English.

## Add a diary entry

1. Copy `entry-template.html`.
2. Create a new file in this folder named `YYYY-MM-DD-short-title.html`.
3. Replace every bracketed placeholder: page title, description, date, and paragraphs.
4. Add the new entry to the list in `index.html), newest first.
5. Preview the page on mobile and desktop before considering it ready.

## Editorial notes

- Publish only entries intentionally approved for public release.
- Keep entries concise, sincere, and grounded in the fictional Koubai setting.
- Do not imply real-world personal experiences or biographical facts that have not been approved for public disclosure.
- Use the date the entry is intended to represent; do not invent historical dates.

The template is `entry-template.html`. It is a starting point, not a published diary entry.
