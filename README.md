# Koubai

The official website of Koubai, a small corner of the internet for notes, projects, and things made with care.

## Website

The site is a lightweight, responsive single-page website built with plain HTML, CSS, and a small amount of JavaScript. It has no build step or package dependencies.

## Run locally

Open `index.html` in a web browser, or serve the repository with any static web server.

## Deployment

This repository is named `redplum701.github.io`, so GitHub Pages can serve the site at:

[https://redplum701.github.io](https://redplum701.github.io)

In the repository settings, enable GitHub Pages and select the default branch as the deployment source if Pages is not already enabled.

## Customize

Edit `index.html` to update the introduction, project cards, notes, and links. The page styles and blossom illustration are included in the same file.
